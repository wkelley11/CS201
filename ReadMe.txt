This program allows the user to play the game Hangman.

The game variables are controlled by getter and setter methods defined in Hangman.java,
except numParts, which I initialized in the Driver class as well to see what the difference
in ease and functionality would be.

To choose between guessing a letter and word, an input of "L" or "l" will call the 
prompt for a letter guess, while any other input (not just "w" or "W") will call the
word guess prompt.
